## 02 角色场景与道具模板

先把同一个人、同一个地方、同一件道具定下来，后面换镜头时有依据可对照。

包含：人物正侧背三视图、表情与服装、空间基准、多角度场景、道具白底图和状态版本。

用完可以整理出：人物定妆图要求＋场景道具资产清单＋一致性检查表。

下载：02_角色场景与道具模板.zip（见附件下载区）。

### A01 人物正侧背三视图

什么时候用：固定人物外貌与服装。

准备：角色描述、定妆参考图、画幅。

直接复制下面整段，再替换【】。

```text
为【角色描述】制作同一角色的正面、侧面、背面三视图参考图，横向三栏，完整全身、同等身高比例、中性站姿、简洁灰色背景、均匀柔光。严格保留参考图的脸型、发型、服装剪裁、鞋与配饰。三栏是身体真实旋转，不能镜像翻转；左右特征按角色自身左右。只出现同一身份的三种视角，无新增角色、无文字水印。
```

示例填写：林夏，22岁，短黑发，深灰长外套，左耳小银耳钉；横向3栏。

检查点：三栏同一个人；背面衣服一致；全身没有裁脚；左耳未反转。

### A02 人物表情与情绪参考

什么时候用：换表情时保留同一张脸。

准备：已确认定妆图、表情列表。

直接复制下面整段，再替换【】。

```text
以【定妆参考图】为同一人物依据，制作【表情列表】的头肩近景参考组。统一机位、镜头距离、背景和光线，保留脸型、五官比例、发型、年龄与配饰，只改变表情。用眼神、眉部、嘴角和呼吸表现情绪，避免过度夸张和身份变化。若用途是内心独白，保持嘴部闭合，允许微表情。
```

示例填写：警觉、疑惑、克制的悲伤；林夏闭嘴，眼睛看向画面右侧。

检查点：表情有区别但没有换脸；闭嘴独白没有说话口型。

### A03 同一人物服装状态版

什么时候用：人物淋雨或受伤，不能变成新角色。

准备：基础定妆图、需要改变的状态。

直接复制下面整段，再替换【】。

```text
在【人物基础参考图】上制作【状态变化】版本。固定身份、年龄、脸型、发型、衣服款式与配饰；只修改指定状态，说明修改位置与范围。输出基础版与状态版的对照说明，并命名为【角色ID】_【状态】_v01。不要添加没有剧情依据的伤口、血迹或新衣服；保留未指定区域。
```

示例填写：CHAR_001_雨湿_v01：外套肩部和发梢淋湿，左耳银耳钉保留。

检查点：状态变化局部明确；基础身份和衣服款式未变。

### A04 场景空间基准图

什么时候用：先固定房间结构再换镜头。

准备：地点、平面关系、时间、风格。

直接复制下面整段，再替换【】。

```text
生成【场景描述】的空间基准图。固定门、窗、走廊转角、家具和关键道具的位置；机位：【机位】；剧情时刻：【状态与时间】；光源：【方向】；画幅：【比例】。画面展示清楚的空间关系与可走动区域，不混入不同时间状态。只生成场景，不出现角色；不要自动增加火灾、破坏或其他未发生的剧情。
```

示例填写：旧公寓走廊；尽头一扇木门，左侧窗、右侧壁灯；雨夜，尚未开门。

检查点：门窗位置明确；不会把以后发生的事件提前画进去。

### A05 同一场景换机位

什么时候用：换角度时空间结构不乱。

准备：场景基准图、新机位。

直接复制下面整段，再替换【】。

```text
以【场景基准图】为同一地点，生成【新机位】的画面。保留门窗、家具、墙面材质、关键道具和当前剧情状态；仅改变观察位置与朝向。先文字说明新机位能看见什么、哪些物体被遮挡，再写生成提示词。不得镜像翻转整个房间，不增加另一扇门或改变走廊长度；参考图未覆盖的位置标为待确认。
```

示例填写：从门内看向走廊；左侧窗在反向机位下应有合理方位，不能机械照搬画面左右。

检查点：是同一个空间；机位变化能由空间布局解释。

### A06 道具白底与多视角参考

什么时候用：固定关键物品的外形与细节。

准备：道具描述、参考图、必要视角。

直接复制下面整段，再替换【】。

```text
为【道具描述】制作独立物品参考：正面、侧面、背面或关键细节【选择视角】，简洁浅灰背景、均匀光线、准确材质和尺度关系。只出现物品，不出现人物、手或使用场景。保留【关键特征】，不自行添加品牌、文字和装饰。如果细小刻字不稳定，预留干净区域，注明后期添加。
```

示例填写：PROP_001旧黄铜钥匙，圆形匙柄、一个缺口，约掌长；房号刻字后期添加。

检查点：道具轮廓一致；没有变成不同产品；文字没有靠模型硬拼。

### A07 道具损坏与使用状态

什么时候用：同一件物品要有前后状态。

准备：道具基础图、剧情状态。

直接复制下面整段，再替换【】。

```text
以【道具参考图】制作【状态】版本。保留尺寸、主要轮廓、材质和关键辨识点，只改变【明确变化】。给出PROP编号、版本名、变化位置和前后对照检查点。区分“物品自身状态”和“被谁拿着”；本次只做物品参考图，无人物和手。未确认的破损程度不要自行扩大。
```

示例填写：PROP_001_沾水_v01，只增加表面水滴，不改变钥匙齿形。

检查点：变化可复原和追溯；同一把钥匙仍能被认出来。

### A08 婴儿与动物姿态约束

什么时候用：容易生成成成人姿态或拟人动作时使用。

准备：主体年龄或物种、支撑、动作。

直接复制下面整段，再替换【】。

```text
生成【主体】在【场景】的参考图。明确真实年龄或物种、身体比例、接触地面或被支撑的位置。婴儿按【姿态】被安全承托，不能误画成独立站立或走路；四足动物保持物种正常骨架、四肢与运动方式，不无故变成人体站姿。只表现【单一动作时刻】，保留参考外观，避免把多段动作拼进一张图。
```

示例填写：出生婴儿躺在成人前臂与手掌承托处；或普通猫伏在窗台四足自然接触。

检查点：支撑关系看得见；姿态符合主体，而不是泛用人体动作。

### A09 统一视觉风格板

什么时候用：不同资产看起来属于同一部作品。

准备：剧本气质、参考图、主色和材质。

直接复制下面整段，再替换【】。

```text
根据【剧本气质】和【参考图】，提炼这部短剧的视觉规则：色彩、光源方向与软硬、材质、对比、空间年代、人物造型。给人物、场景、道具各一条共用风格描述，并列出不该出现的元素。把身份与风格分开：风格可一致，但不能把不同人物变成同一张脸。不要堆积互相矛盾的摄影或艺术流派名称。
```

示例填写：现代悬疑；冷灰雨夜、壁灯少量暖色、旧木与黄铜材质、写实人物。

检查点：三类资产相互协调；光线与时代设定没有冲突。

### A10 资产清单与一致性检查

什么时候用：素材多了，避免错用。

准备：角色场景道具图、对应剧本。

直接复制下面整段，再替换【】。

```text
对照【资产图】与【已确认剧本】，建立资产表：ID、名称、用途、基础版、状态版、实际文件名、待补图片。检查人物脸型服装左右特征、场景门窗关系、道具外形与持有状态。发现问题说明具体哪张图哪里不一致，给最小修复方案。只能核对实际能看到的图片，未上传素材不能写“已一致”。
```

示例填写：CHAR_001定妆与雨湿版；LOC_001门外与门内机位；PROP_001干燥与沾水版。

检查点：文件实际存在；状态版本不会混用；未看见的不做通过结论。
