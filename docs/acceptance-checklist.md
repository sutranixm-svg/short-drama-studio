# 素材对照验收清单（P20/A10 · P40/P10）

用于核验**在外置软件（即梦 / 可灵 / 百炼等）按提示词手工生成**的素材，判定「可留用 / 需修改 / 需重生成」。
资产类走 `A10 资产清单与一致性检查`；镜头生成类走 `P10 参考图与生成结果对照`。
提示词正文见 `skills/drama-assets/references/prompt-templates.md` 与 `skills/drama-prompts/references/prompt-templates.md`。

## 一、先把这张表填实

验收不能凭描述进行，必须有可看的文件。缺任何一项都只能给出「未核验」。

| 字段 | 填什么 | 示例 |
| --- | --- | --- |
| 素材类型 | 角色三视图 / 场景基准图 / 道具图 / 第X镜首帧 / 第X镜视频 | 角色三视图 |
| 编号与版本 | 资产 ID + 版本号 | `CHAR_001_v01`、`shot_03_v01` |
| 文件 | 本地路径或直接上传 | `workspace/ep01/CHAR_001_v01.png` |
| 原始参考图 | 定妆图 / 场景图路径；没有就写「无」 | `workspace/ref/CHAR_001_base.png` |
| 对应剧本段落 | 该素材服务的场次或镜号 | 第 3 集 · 镜 03 |
| 引擎与提示词 | 哪个平台、用的哪条提示词 ID | 即梦 · P11(A01) |

## 二、资产类验收（A10）

逐项对照**实际能看到的那张图**，看不清就写「未核验」，不要写「通过」。

**角色三视图**
- [ ] 三栏是同一个人（脸型、五官比例、年龄一致）
- [ ] 正面 / 侧面 / 背面是真实旋转，不是镜像翻转
- [ ] 左右特征按角色自身左右（如左耳耳钉没有跑到右耳）
- [ ] 服装、鞋、配饰在三栏一致
- [ ] 全身完整，没有裁脚、没有多出手指或肢体
- [ ] 无文字水印、无新增角色

**场景基准图**
- [ ] 门、窗、走廊转角、家具位置明确
- [ ] 光源方向与剧情时刻一致（如雨夜、尚未开门）
- [ ] 没有把后续剧情（火灾、破坏）提前画进去
- [ ] 画面内无角色（基准图默认不含人）

**道具图**
- [ ] 轮廓与关键辨识点一致（如钥匙的缺口、齿形）
- [ ] 只出现物品，无人物、无手、无使用场景
- [ ] 需要后期加的细小刻字留在干净区域，没有靠模型硬拼

**状态版本（湿衣 / 破损 / 沾水）**
- [ ] 只改了指定状态，基础身份与服装款式未变
- [ ] 变化位置局部明确，没有扩大
- [ ] 有基础版与状态版的对照

## 三、镜头生成类验收（P10）

**首帧 / 尾帧**
- [ ] 首帧是「动作开始前一刻」，不是动作结果
- [ ] 与上一镜尾状态接得上（人物位置、朝向、道具在哪个手）
- [ ] 尾帧只改了动作造成的变化，其余不变

**单镜视频**
- [ ] 成片 1—3 秒，动作有明确起落点
- [ ] 没有换脸、没有换装、没有道具突然换手
- [ ] 无背景音乐（BGM 属后期）
- [ ] 对白镜头：口型与句子长度匹配，没有多说字
- [ ] 独白镜头：嘴部闭合，不出现说话口型
- [ ] 运镜只有一种，幅度在 1—3 秒内能完成

## 四、判定规则

| 判定 | 条件 |
| --- | --- |
| **可留用** | 全部检查项通过，且与剧本、参考图无冲突 |
| **需修改** | 存在局部错误（多一根手指、左右特征反转、道具状态不对），整体构图与身份可保留 |
| **需重生成** | 身份变了（不是同一个人）、空间结构错了（多一扇门、门窗位置反了）、动作与剧本冲突 |

## 五、需修改时：局部修改提示词模板（P39 / P09）

复制后替换【】，只贴回原平台，不要重画整张：

```text
修正【原图】的【错误区域】：改为【目标状态】。保留人物身份、整体构图、未指定区域、场景布局和光线，只修改明确区域。先说明最小修改范围，再给局部修图提示词与修改后检查点。需要遮罩时提示我圈选实际错误位置，不编造已经使用遮罩。不能因修一只手而重画脸与服装。
```

填写示例：
- 角色图 → 「将右手多余的一根手指改为自然握钥匙的手势，保留脸、外套与钥匙形状」
- 场景图 → 「只把左侧窗户向内移 10%，保留右侧壁灯、木门与走廊长度」
- 道具图 → 「钥匙齿形改回三齿，其余材质与缺口不动」

## 七、没有文件时怎么办

如果只有文字描述（没有图片或视频文件），本清单的每一项都无法勾选——判定只能是「未核验」。
此时能做的只有：确认编号与版本命名、确认该素材应服务的镜号、准备好参考图路径，等文件到位后再验收。
